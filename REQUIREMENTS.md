# Requirements

## Users

- **Scorer:** controls the match, lineup, rotations, substitutions, sanctions, audio, and score.
- **Second referee:** reads current score, service order, rotations, libero state, and 5-1 receive plan on a phone or tablet.
- **Fans/broadcast operator:** views the dedicated auxiliary scoreboard.

## Functional Requirements

- Score best-of-five matches: sets 1-4 to 25 and set 5 to 15, each with a two-point lead.
- Preserve the final set score in match results and permit manual end only when the match is complete.
- Rotate only on a receiving team's side-out; show P1-P6 server order and active libero state.
- Allow 5-1 and 6-0 per team. The 5-1 visual plan must always show the team receiving service.
- Enforce up to two timeouts per team per set and the configured 30-second timeout after a four-second introduction.
- Enforce no more than eight standard substitutions per team per set. A substitute can only return for the player they replaced; libero exchanges are excluded.
- Support a closable overlap assistant. It is a visual aid, not an official ruling.
- Allow registered teams and visitors to show logos; arbitrary team names remain valid with no fallback logo.
- Provide a fan-facing scoreboard and a read-only second-referee link generated by QR code.

## Constraints

- The main dashboard has no staff authentication; deployment access must be controlled externally until authentication is added.
- The core console must work from static hosting without a build process.
- OBS credentials must never be committed or exposed in a hosted browser build.
- Live-share state is limited to 400 KB per function request.

## Acceptance Criteria

- A scorer can complete a 3-0, 3-1, or 3-2 match and see the final set in the summary.
- A second referee receives score and rotation updates within roughly two seconds of a saved scoring action.
- Custom team names render without broken-image icons.
- The scoreboard remains legible at full-screen 1080p and handles narrower displays without overlapping content.
- `node tests/matchRules.test.js` passes before release.
